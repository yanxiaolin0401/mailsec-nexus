# 页面、导航与全栈交互需求

> v1.1 草案 · 对应 [IAM/SRC/DET/CAS/ADM](../综合需求分析.md)。正式平台目标，现有 smart-search 轻量 Web 不视为已实现这些页面。

## 1. 信息架构

导航以分析员工作流组织，模块名称作为能力标签，不让用户在三个独立站点重复登录/复制邮件 ID。用户顶栏显示当前租户/项目、任务通知和用户；管理员后台顶栏显示管理身份、全平台/目标租户范围；侧栏只呈现已授权且已部署的能力。未上线模块在管理页显示“未部署”，不是可点开的空功能。

| 区域 / 路由建议 | 主要内容与动作 | 阶段/权限 |
| --- | --- | --- |
| `/login`、`/auth/callback` | “用户租户登录/管理员登录”双模式、身份认证、管理员MFA及错误提示 | S1；服务端校验真实身份类型与模式，不能切换按钮提权 |
| `/overview` | 已接收/已索引/未知风险、案件积压、数据新鲜度、组件降级 | S1；仅当前域；不是全局数据泄露的总览 |
| `/mail/search` | 过滤器、自然语言、计划预览、统计、结果表、保存/共享查询 | S1；查询权限 |
| `/mail/:eventId` | 邮件摘要、证据/正文、检测与 AI、分析历史、关联案件；S2 增加路由证据 | S1→S2；原文/下载额外授权 |
| `/ingestion/sources` | 来源及绑定项目、凭据轮换、最近接入、错误分布、合成测试 | S1；由后台管理员配置，用户仅查看获分配来源 |
| `/ingestion/imports` | EML/批导入口、格式/容量/授权说明、上传进度、导入回执 | S1；导入权限 |
| `/tasks`、`/tasks/:id` | 导入/分析/导出/回测进度、阶段/attempt、失败项、取消/重试/下载 | S1；用户本人/共享任务，管理员可管理全平台任务 |
| `/cases`、`/cases/:id` | 分派/优先级、邮件/告警关联、证据时间线、评论、复核、报告、关闭/重开 | S1；案件资源范围 |
| `/analysis/sops` | 排查模板、范围预览/估算、模型预算、执行和部分报告 | S1/P1；分析与外发双权限 |
| `/header/workbench` | 方言分组、异常字段、可信路由链、有序头定位、流向未知解释 | S2；解析研究权限 |
| `/header/versions` | 候选代码/测试、基线差异、回放报告、审核/灰度/回滚 | S2；研究与发布权限分离 |
| `/threat/alerts`、`/threat/campaigns/:id` | 外部告警导入/关联、行为簇、时间线/关系图、支持/冲突证据 | S3；授权告警和调查范围 |
| `/rules`、`/rules/:id` | 规则定义/版本、回测、误报/漏报、审核、影子/启用/停用 | S3；用户提交候选，管理员审核确认发布 |
| `/experiments`、`/experiments/:id` | 样本集/标签/切分、算法版本、参数、指标/置信区间、错例 | 分阶段；研究域，不默认读取全部样本 |
| `/admin/overview`、`/admin/tenants`、`/admin/users` | 全平台总览、租户/用户创建停用、user/admin类型及租户归属 | S1；仅后台管理员，不设租户管理员子后台 |
| `/admin/data/*` | 跨租户邮件正文/附件、案件、任务、实验、导出与受控修改/删除 | S1；管理员最高数据读写权，操作显示目标租户并审计 |
| `/admin/settings/*`、`/admin/audit` | 来源/模型/配额/留存、组件/存储/模块状态、审核发布与审计 | S1；统一后台管理员权限 |
| `/profile/security` | 会话、个人设置、通知、关联身份、退出 | S1；仅本人 |

### 1.1 登录页双模式交互

- 页面提供显式Tab/切换项：“用户租户登录”“管理员登录”，默认用户租户模式。
- 用户模式显示租户标识/选择及账号认证入口；管理员模式隐藏租户必填项，显示管理员认证与MFA流程。认证可由OIDC身份服务承载，不因双模式另建密码体系。
- 成功落地分别为 `/overview` 与 `/admin/overview`；失败提示模式/账号不可用，不泄露其他租户成员信息。
- 认证请求与回调必须绑定服务端登录模式；表单mode、URL和菜单状态均不能充当权限。用户/管理员账号与模式不匹配时拒绝，不创建另一身份的会话。
- 已登录后切换模式必须退出并重新认证；清空查询、详情、任务缓存和选择项。管理员进入业务数据视图仍显示管理员身份和目标租户，不伪装用户登录。

## 2. 三个关键页面契约

### 2.1 邮件检索与自然语言

- 左/上方为结构化条件，中央为摘要列表，右侧或下方为计划/说明；窄屏改抽屉和卡片，不强塞多栏。
- 允许字段、时区、时间窗、已选项目可见；缺省风险是未知，不能用绿色占位。多收件人显示摘要+总数，详情按权限展开。
- NL 输入 → 受限计划预览（原意、时间解析、字段条件、被拒原因、预估范围）→ 用户执行。SQL 若显示，仅为服务端模板说明；不提供自由 SQL 编辑器。
- 搜索与表格分页同步；空结果、过滤过窄、索引延迟、权限不足、模型不可用与系统错误分别提示。
- 页面 URL 不携带邮箱/正文/自然语言等敏感查询；需要分享时保存服务器端受权查询 ID，收件人再次鉴权。后台安全日志也不记录完整请求体。
- 跳详情/案件时保留合法查询上下文；选中项进入批任务前重新验证范围，不跨租户沿用选择。

### 2.2 邮件详情与证据研判

- 概览展示时间、来源、收发信息、解析/索引状态、风险和人工标签；事件 ID 与原 `Message-ID` 分开。
- 标签页：基本字段、正文/原文、检测证据、AI 意见、分析历史、关联案件；S2 路由、认证、伪造/流向用新增能力页签呈现。
- 每条结论可定位具体头字段/字节引用/附件哈希/规则信号，展示来源、版本、时间、完整性。认证头“上游声称”与本系统验证区分。
- 模型调用按钮展示外发字段类别、授权状态与额度；无权限、无模型、无完整原件各有解释，不能统一显示“安全”。
- 附件默认不可在线执行；名称/大小/哈希不等于已获得字节。下载需额外权限、警示及审计。
- 人工标签不得覆盖原始 AI 结论；保留变更理由/复核人。恶意提示内容只显示为文本。

### 2.3 管理员后台

- 仅后台管理员可进入统一后台；可访问全部租户正文/附件并读写业务数据，不需要租户额外授权。用户入口不显示管理菜单，直接请求后台API仍须被服务器拒绝。
- 模型：provider/base URL/model、凭据只写、合成连通、字段策略、单次/日预算、失败/耗时；不显示真实 key，不测试性批发历史邮件。
- 调控：租户接收/查询/分析并发和配额、来源停启、留存、任务重试、检测器状态、规则/解析器版本及开关。限制有范围、合法区间、变更预览、审计与回滚值。
- 危险操作（扩大外发、降低留存、删除、批导出、规则启用、管理员权限变更）显示影响范围和复核步骤；不能只有一个没有说明的开关。
- 健康状态区分进程存活/依赖可用/业务积压/部分降级；展示最近更新时间，不能用静态绿色图标装饰。

## 3. 通用交互与无障碍

- 每个数据页面具备 loading、empty、forbidden、error、partial、stale 六类状态，附可执行恢复方式；过期会话回登录且不丢失非敏感草稿。
- 表格服务端筛选/排序/分页，稳定行键；大表不一次加载全部。重试写请求保留幂等键；重复点击不创建重复任务。
- 长任务接受后立即显示任务 ID 和可恢复的进度页；刷新/重登录仍可查历史。进度未知用阶段/已处理数，不伪造百分比。
- SSE 为可选增强，轮询为基线；断连后恢复状态查询，事件流本身不是唯一进度来源。
- 通知只发最小必要信息（任务完成/需审核），邮箱/Webhook 不带原始邮件和凭据；外部通知 P1 可关闭。
- 全局时间存 UTC、展示租户时区（默认 Asia/Shanghai），筛选明确边界与相对时间锚点；日期、编号和下载名一致。
- 目标视口 1440/1024/768/375 px；主页面无意外水平溢出。复杂证据表可在明确容器内滚动，手机仍能查询、看详情、审查任务/案件。
- 键盘完整操作、焦点与标签、对比度、非纯颜色表达风险；以 WCAG 2.2 AA 为设计/测试目标，不以自动扫描代替人工键盘验收。
- 统一设计 token（色彩/间距/字号/密度/风险语义）、组件状态与国际化文本位置；不在三个模块重复实现不同的确认框/错误页。

## 4. 前后端联调验收旅程

1. 管理员模式登录 → 建租户/用户/项目/来源 → 退出 → 用户租户模式登录 → 合成JSON导入 → 任务done → 搜索到结果。
2. 平台用户 NL 预览 → 执行 → 看详情 → 授权模型/静态检测 → 人工复核 → 建案件/关闭。
3. 第二租户或同租户无权用户使用第一用户的详情、任务、对象和报告 ID → 均被拒绝，且无内容/数量泄漏。
4. 模型停用/超时 → 页面显示未知/降级 → 结构化检索和案件仍可用。
5. 管理员轮换来源密钥/撤销用户 → 旧凭据/会话不能继续访问；刷新和浏览器返回也不展示缓存敏感内容。
6. 普通用户选择管理员模式或伪造role/tenant参数 → 登录/后台API拒绝；管理员登录后跨两租户读写成功、范围清晰且有审计；退出/降权后旧会话拒绝。
7. S2/S3 上线后从同一邮件进入头部证据、告警、规则实验和案件；未上线阶段不做空壳演示。

每条旅程留 Playwright/真实浏览器报告、桌面/手机截图、控制台错误、接口契约及追踪 ID。截图不替代服务端权限测试；OpenAPI 页面不替代正式前端验收。
