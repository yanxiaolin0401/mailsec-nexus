# 系统级验收测试（规划）

跨模块测试按 **smart-search → header-parser → threat-trace** 分阶段增加，平台身份、前端、隔离和部署测试不等到最后。

- S1：用户租户/管理员双模式登录，双租户/多项目用户隔离与管理员全平台读写验证 → JSON/EML接入 → 持久回执/索引 → 检索/NL预览 → 研判 → 案件/复核 → 报告；覆盖降级、越权、撤权和故障恢复。
- S2：从同一邮件查看有序头、可信路由和伪造/流向；候选解析器隔离回放、审核、灰度/回滚；不破坏S1。
- S3：告警关联 → 行为/规则实验 → 留出回测 → 管理员审核确认/影子生效 → 命中回流案件；不把图谱展示当算法验收。
- R1：全栈浏览器、容量、安全、存量迁移、新机部署、备份恢复、升级/回滚与运维移交。

用例与证据要求见[算法与质量矩阵](../docs/product/算法实验与质量验收.md)和[生产门禁](../docs/product/工程交付与实施路线图.md)。本目录当前仍为规划，不表示已有这些系统级测试。模块内部单元/回归测试保留在各自 `tests/`，不在此复制。
