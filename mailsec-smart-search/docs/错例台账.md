## 检测错例

本机评测生成 `reports/detection-baseline.errors.jsonl`，仅含内容hash、来源、标签和引擎状态，原始邮件在data目录按清单查找。Spam标签不是恶意附件标签，ClamAV对spam不报签名不能称为“恶意附件漏报”。历史语料、离线规则和顺序取样会影响结果，不能据此宣称企业准确率。

未做真实模型错例复盘：需要有效第三方接口和获授权评测输入。不得用mock模型数据填充真实准确率。
