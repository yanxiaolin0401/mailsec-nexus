# 题目5 基于大模型的邮件数据分析与智能检索系统开发

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 项目类型 | 网络安全应用+大数据分析与可视化 |
| 技术难度 | 高级 |

## 项目目标

1. 基于离线邮件分析场景，构建具备高吞吐存储检索能力与智能分析的前端交互系统。
2. 实现对海量邮件数据的多维高效查询(ClickHouse/Elasticsearch)。
3. 支持用户对特定的搜索结果进行大模型分析，判定是否恶意邮件。
4. 用户可在使用系统时调用大模型进行查询语句的优化。
5. 开发生产级可用的邮件数据解析与清洗引擎，确保导出的解析器代码具备高鲁棒性与高执行吞吐，规避正则爆栈等安全隐患，保障生产环境可用性达到 99% 以上。

## 技术要求

1. 掌握SMTP协议，了解常见的邮件头
2. 熟悉ClickHouse、Elasticsearch等分布式存储引擎
3. 掌握基本的性能调优方法
4. 掌握大数据查询下的超时控制、大结果集流式响应及并发限制，确保查询失败时系统能够优雅降级，保障系统可用性。
