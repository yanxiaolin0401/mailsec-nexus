# 演示提纲（约8分钟）

1. **问题与边界**：独立模块、HTTP8080、自部署ClickHouse；为何模型不直接执行SQL、扫描失败不等于正常。
2. **数据准备**：展示data清单、526,913封原始样本与许可证限制；压缩包清空、原始证据保留。
3. **接收链路**：先投递合成嵌套 JSON，说明 `202` 是可靠入队而非已入库，再展示事件列表/详情；另演示 EML 兼容路径及其独立去重语义。
4. **容量与检索**：展示旧 EML 真实导入报告、独立条数、并发1/4查询p50/p95；另说明新 JSON 10 万负载尚待独立压测，不把批导吞吐称为持续生产 SLA。
5. **分析与证据**：一封邮件分别显示Rspamd、ClamAV、模型状态及融合。没有key时现场明确展示model unavailable而不是伪装智能结果。
6. **安全操作**：无 token 401、超限 413；新事件 NL 对邮箱/IP/URL本地占位，拒绝不支持的部门映射和注入；先预览固定模板计划，再显式执行。没有有效 key 时展示明确降级。
7. **排查流程**：预览发票/未验证SPF声称/双后缀附件；说明最近窗口和不完整标志。
8. **工程与后续**：回归测试、错例台账、恢复/重试；补真实LLM联通与企业标签验收，不承诺普适最佳算法。

可复现入口：`scripts/smoke_http.py`、`scripts/benchmark.py`、`scripts/evaluate_detectors.py`、`scripts/smoke_model.py`。真实邮件内容不放公开演示截图。
