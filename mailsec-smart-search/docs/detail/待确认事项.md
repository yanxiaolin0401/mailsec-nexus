# 决策记录（更新于 2026-10-21）

## 已冻结

- 首版 **HTTP 8080**，主输入为嵌套 JSON；原始 EML / multipart 为兼容入口，不实现 SMTP。
- 自部署 ClickHouse；不要求 Elasticsearch DSL；本模块独立开发。
- 本机扫描选 **Rspamd + ClamAV**；ClamAV是静态签名扫描，不是附件执行沙箱。
- 允许发送**已获授权的脱敏字段**至第三方模型；接口双协议，密钥经环境配置，默认关闭外发。
- 大语料使用 Enron；垃圾邮件与钓鱼分别使用 SpamAssassin / Nazario；不得把 Enron 统标为正常。
- 自然语言只开放受控只读查询/统计；轻量 Web 为必做交互终端，CLI + OpenAPI 为辅助；JSON 推送和 EML 上传/导入均由明确入口接收。
- 数据统一存放项目 `data/`，验证成功后删除下载压缩包，根目录不存样本、压缩包或日志。

## 最后需要外部提供的输入

1. 第三方服务的 **HTTPS base URL、model、有效 API Key**（不要粘贴到公开文档，写本地 `.env`）；用于真实联通和模型/融合评测。
2. 企业带标签且授权的脱敏验收集，以及最终时延/误报/漏报阈值；没有时只报告公开集实测，不替企业签收。

其余本机开发、数据准备、安装与测试无需再次确认。公开集没有经过“全量允许外发”审核，因此不会自动提交给第三方模型。
