# 题目6 基于大模型辅助生成的异构邮件头解析与伪造流向研判系统

## 基本信息

| 项目     | 内容                  |
| -------- | --------------------- |
| 项目类型 | 网络安全+人工智能应用 |
| 技术难度 | 高级                  |

## 项目目标

1. 针对 Coremail、Exchange、Postfix、O365 等多源异构邮件服务器的 Header 方言与协议差异，借助大模型分析未知方言并辅助生成高效、确定性的 Python 邮件解析器代码，实现发件人伪造识别与流向（01/10/00/11）精准判定。
2. 构建"数据抽样 -> 大模型归因分析 -> 解析代码/正则辅助生成 -> 自动化单元测试验证"的解析器演进闭环，支持从 Postgres/ES 提取历史日志进行反向验证。
3. 生产环境中运行的纯 Python 解析代码对发件人伪造与流向判定的准确率达到 99%。
4. 导出的解析器代码具备高鲁棒性与超高执行吞吐，无正则爆栈隐患，生产环境可用性达到 99%。

## 技术要求

1. **异构方言分析与代码生成**：利用 Agent 自动提炼不同邮件服务器的 Received 路由链与认证头方言特征，并生成对应的 Python 解析函数与正则表达式。
2. **发件人伪造与中继还原**：解析代码需精准提取真实第一跳 IP、中继节点、SPF/DKIM 校验及 From/Sender 对应关系，识别伪造标头。
3. **测试驱动与代码精简**：自动生成针对异构样例的单元测试，使用简化与性能审查工具（如 simplify）确保生成的解析代码结构清晰、无冗余抽象与正则性能隐患。
4. **生产环境工程落地**：生成的解析代码集成至生产版本，高性能处理与 Docker 容器化部署。
